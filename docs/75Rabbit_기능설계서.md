# 75Rabbit 기능설계서

## 1. 서비스 목적

75Rabbit은 배드민턴 운동 모임의 생성, 참가신청, 참가현황 확인, 대진 생성, 경기 결과 입력, 전광판 운영을 하나의 모바일/웹 환경에서 처리하는 모임 관리 프로그램이다.

## 2. 사용자 유형

| 사용자 | 설명 | 주요 기능 |
|---|---|---|
| 참석자 | 운동 모임에 참여하는 일반 사용자 | 참가신청, 참가현황, 대진표, 결과 확인 |
| 운영자 | 당일 운동을 운영하는 관리자 | 체크인, 대진 생성, 결과 입력, 전광판 |
| 최고관리자 | 시스템 설정과 관리자 계정 관리 | 모임 생성, 관리자 권한, 데이터 관리 |

## 3. 참석자 기능

### 3.1 참가신청

- 모임 코드 입력
- 이름, 성별, 급수, 휴대폰 뒤 4자리 입력
- 희망 종목 선택: 남복/여복/혼복/랜덤
- 파트너명 또는 메모 입력
- 신청 완료 후 참가현황으로 이동

### 3.2 참가현황

- 신청자 수, 대기자 수, 체크인 수 표시
- 본인 신청 상태 확인
- 관리자가 허용한 항목만 공개

### 3.3 대진표

- 라운드별 보기
- 코트별 보기
- 내 이름 검색 및 내 경기 강조
- 경기 상태: 예정/진행중/종료

### 3.4 대진결과

- 경기 점수 확인
- 승패 확인
- 개인별 전적/순위는 2단계 기능으로 확장

## 4. 관리자 기능

### 4.1 모임 생성

- 모임명
- 날짜
- 장소
- 시작/종료 시간
- 코트 수
- 정원
- 모임 코드
- 모집 상태: 모집중/마감/진행중/종료

### 4.2 참가자 관리

- 신청자 목록 조회
- 참석/대기/취소/체크인 변경
- 현장 참가자 추가
- 중복 신청 정리

### 4.3 대진 생성

- 체크인 인원 기준 대진 생성
- 4명 단위 경기 생성
- 코트 수 기준 자동 배정
- 라운드 번호 자동 증가
- 미배정 인원은 휴식자로 표시

### 4.4 대진 수동 수정

- 경기별 선수 교체
- 코트 변경
- 라운드 변경
- 경기 삭제/추가

### 4.5 결과 입력

- A팀/B팀 점수 입력
- 승리팀 자동 계산
- 경기 상태 종료 처리

### 4.6 전광판

- 현재 진행 경기 표시
- 다음 경기 표시
- 코트별 경기 카드
- 전체화면 모드
- 자동 새로고침 또는 Realtime 반영

## 5. 업무 흐름

### 참석자 흐름

```text
링크 접속 → 모임 코드 입력 → 참가신청 → 참가현황 확인 → 대진표 확인 → 결과 확인
```

### 관리자 흐름

```text
로그인 → 모임 생성 → 신청 링크 공유 → 참가자 관리 → 현장 체크인 → 대진 생성 → 전광판 공개 → 결과 입력 → 통계 저장
```

## 6. MVP 범위

- 모임 생성
- 참가신청
- 참가현황
- 관리자 로그인
- 참가자 체크인
- 대진 자동 생성
- 대진표 조회
- 경기 결과 입력
- 전광판 기본 화면
- 모바일 반응형
